# create-fedi-app

## Register

brand

## Users

Bitcoin and Nostr developers building mini apps for the Fedi wallet. They scaffold projects at a desk, often in a dim terminal-heavy environment, and need to trust the tool before running `npx create-fedi-app@latest`.

## Product Purpose

Market the CLI scaffolder and documentation site. Convert curious developers into first-time scaffolds. Explain what Fedi injects into the browser and what the generated project includes.

## Brand Personality

Mechanical, warm, direct. Speaks like a senior engineer who respects your time. Orange signal on near-black. No hype, no SaaS theater.

## Anti-references

- Purple gradient SaaS landing pages
- Icon-tile feature grids
- Glassmorphism and neon glow
- Editorial magazine layouts (italic serifs, drop caps, broadsheet grids)
- Cream/beige backgrounds
- Marketing buzzwords (supercharge, empower, streamline)

## Strategic Design Principles

- Dark theme: developers reviewing CLI output in low light
- Fedi orange as committed accent, not decoration
- Mono reserved for code and API names only
- Asymmetric layouts over centered stacks
- Terminal and API diagrams as primary imagery (no stock photos)
